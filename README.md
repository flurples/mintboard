# mintboard
a 40% bluetooth keyboard built into an altoids tin

<img width="1920" height="1080" alt="IMG_0049" src="https://github.com/user-attachments/assets/e1585383-4cfa-400d-96a2-07cbcaee506f" />
build video: https://youtu.be/VZ1lAV-ThZo

## you will need
- an altoids tin
- a mintboard pcb
- 1x top and 1x bottom housings
- keycaps ( 32x 1u, 2x 1.25u, 4x 1.5u, 2x 1.75u, 1x 4u)
- a nice!nano
- a small battery (I used a [301230](https://typeractive.xyz/products/lithium-battery-110mah?_pos=1&_sid=1f1b588b2&_ss=r) 110 mah lithium battery from typeractive)
- a [OS202011MA0QN1](https://www.digikey.com/en/products/detail/c-k/OS202011MA0QN1/1981434?so=84718120&content=productdetail_US&mkt_tok=MDI4LVNYSy01MDcAAAGQVwdjiVGonvzkfjpSeKMOLfsL14AKEAxTyVseBkvXUuhdkCoQ9XYS7CoJXYxmb_hU999OJmHqsBVxQt5MaQLbL1UVmK6itZdC7dEBY8wV) or equivalent power switch
